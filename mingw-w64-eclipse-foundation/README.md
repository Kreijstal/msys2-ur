# Eclipse foundation libraries for MSYS2 UCRT64

This package installs the source-built Eclipse 4.41 foundation stack: Equinox,
the platform core, SWT with native Windows libraries, JFace and the workbench,
EMF, GEF/Draw2d, LSP4J and their runtime dependencies.

With the `msys2ur` binary repository configured, install from a UCRT64 shell:

```sh
pacman -Syu mingw-w64-ucrt-x86_64-eclipse-foundation
eclipse-foundation
eclipse-foundation -data /path/to/workspace
```

The launcher uses the packaged OpenJDK and creates per-user Equinox
configuration under `$XDG_STATE_HOME/msys2-ur/eclipse-foundation`, or
`$LOCALAPPDATA/msys2-ur/eclipse-foundation`, falling back to
`$HOME/.local/state/msys2-ur/eclipse-foundation`. The default workspace is
`$HOME/eclipse-workspace`. Eclipse options and options following `-vmargs`
are forwarded to Eclipse and its JVM respectively.

Additional application bundles can be placed in the per-user `plugins`
directory next to `configuration`; the launcher includes them on its next run.

The workbench opens the resource perspective with platform editors and views.
Java development tools and the full PDE development environment are not part
of this foundation stack; their annotation libraries are included for the
platform's APIs.

Bundles are installed under `/ucrt64/lib/eclipse/plugins`. Applications can
depend on individual packages, for example
`mingw-w64-ucrt-x86_64-eclipse-jface` or
`mingw-w64-ucrt-x86_64-eclipse-swt`, instead of the complete install target.
The build helper's README documents building and configuring RCP applications
against these bundles.

The Java code is compiled from source with the source-bootstrapped OpenJDK.
The Eclipse launcher, SWT JNI libraries and JNA native support are compiled
with MinGW GCC. LSP4J uses the release's published Java source for the classes
normally generated by Xtend; no precompiled Xtend compiler is used.
