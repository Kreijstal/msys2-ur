# SDK10 logging/options/console source bootstrap

Builds the original NET10 profiles of DependencyInjection, Options, Logging,
Options.ConfigurationExtensions, Logging.Configuration and Logging.Console from
VMR `44525024595742ebe09023abe709df51de65009b`, plus the original
NETStandard2.0 Options.SourceGeneration profile against source-built Roslyn4.4.
Production sources are unchanged. Assemblies retain version10.0.0.0, file
version10.0.225.61305, package10.0.2 and the original AspNetCore public key.

The original Binder analyzer executes for both logging configuration projects.
Console's original LibraryImport partial methods are generated by the installed
source-built runtime10.0.5 generators; this framework-tool provenance is retained
separately from the original runtime10.0.2 production source pin.

Six component comparisons cover514 public CLR declarations and nullable
annotations. This is not a complete custom-attribute/constraint/API metadata
comparison. It does not close the previously recorded original DI.Abstractions
25 nullable differences, Primitives one nullable difference, or runtime10's full
framework contract gate.

Runtime checks execute generated Options validation, DI keyed/scoped services
and disposal, configuration binding/reload/error handling, configured logging
filters, queued JSON output, Unicode/event/scopes and native console probing.
Resource checks cover19 neutral/localized sets,515 values,13 satellites and
seven portable PDB associations. Actual offline NuGet7.3 restore must select all
12 NET10 source archives and the original Options/Binder analyzer assets.
The original Options Roslyn-version-selection and disable targets execute.

The original NET10 nullable-validation profile of the Options generator,
other library TFMs, the full upstream test/analyzer policy, complete SDK10,
Windows desktop10 and PowerShell7.6 remain open. This is a prerequisite package,
