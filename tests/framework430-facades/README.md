# Seven original CoreFX 4.3.0 parent packages

Builds Microsoft.Win32.Primitives, System.Console,
System.Diagnostics.Tracing, System.Globalization.Calendars, System.IO.FileSystem,
System.Net.Sockets and System.Runtime.Extensions with every original reference and
Framework facade asset path, alias, marker, documentation file and dependency group.
The validation output records the actual remaining original dependency gaps.

All 12 original reference profiles compile and match 3,871 API entries, identities,
attributes, dependencies, native versions, resources and exported-type records.
A consumer compiles for each profile. Pinned source-build-reference-packages commit
5aeee2738338530a92d7f6caa2c7d5f569fed3c4 supplies unchanged reference declarations.
CoreFX commit 4d1af962ca0fede10beb01d197367c2f90e92c97 supplies the original facade
projects, implementations and resources. Original DLLs are metadata baselines only.

Two exact compiler prerequisites are explicit. The complete 39-entry
System.IO.FileSystem.Primitives 4.0.0 enum contract builds from unchanged CoreFX
source with original assembly attributes. System.Net.Primitives 4.0.10 is extracted
from its already checked installed source NuGet. No newer contract identity is
substituted and neither private compiler contract is a runtime/NuGet substitute.

The Framework System.dll compiler seed is generated by source GenAPI from original
Framework 4.6 metadata. Its 71 selected types include 27 forwarding targets and
their declaration dependencies. All 1,435 API entries and public declaration
metadata round-trip exactly. Original assembly-level CLS compliance is preserved.
The source projection removes four duplicate generated accessor declarations and
one synthesized struct constructor absent from the original. It is reference-only.

The original NET462 EventCounter requires EventSource.EventCommandExecuted, which
is absent from the older Framework 4.6 compiler contract. The complete public
Framework 4.6.2 mscorlib and System.Numerics source contracts are now separately
packaged and installed; see ../netframework462-contracts/package-results-20261031.json.
NET462 facade builds use that exact target contract.

All seven facades compile and match original identities, 25 owned API entries,
94 full exported-type records, native versions and all 148 source resource strings.
The original EventCounter implementation is unchanged. Modern C# adds two nested
Environment exports not present in the original Runtime.Extensions contract;
a strict source Cecil projection removes exactly those two known records.

A narrowly documented SocketTaskExtensions port fixes the accept-socket overload:
BeginAccept(socket, receiveSize=0, ...) returns a receive-buffer result on NET8,
so its matching EndAccept(out acceptedBuffer, result) overload is required.
The new call also exists on the original Framework target. Original source is
preserved; only a copied compilation projection changes. All 22 owned Sockets
API entries, original dependencies and signing identity remain unchanged.

Modern-host execution resolves all 94 exports to source NET8 implementations,
executes original EventCounter buffering/statistics and all 13 original socket task
overloads over owned loopback TCP/UDP fixtures. Both accept forms, all four connect
forms, both send/receive forms, peer metadata and packet destination metadata pass.
This does not establish execution on original Framework runtimes or full historical,
runtime.any/AOT, remote/provider, native or broader PowerShell compatibility.

The self-contained source workflow rebuilds its private Csc 4.4 CLI, reference
profiles, compiler contracts, metadata tools, partial Framework seed and complete
facades. Its source inputs and original baselines are frozen.

```
python build-all.py SBRP_ARCHIVE COREFX_ARCHIVE NEW_PRODUCER PREFIX CSC44
python pack.py PRODUCER NEW_ARCHIVES PREFIX
python check.py FEED PRODUCER/references/private-contracts NEW_CHECK PREFIX CSC44
```

The complete checker extracts the actual candidate/installed NuGets, repeats the
12 reference consumers and all original metadata checks, executes the owned
Counter/socket implementations, and verifies NuGet compile/runtime asset selection.
Fresh original NETStandard.Library 1.6.1 restores retain and report unresolved
package IDs; a successful parent-package check does not claim full graph closure.
Installed checks accept the validated private compiler contracts as an explicit
input, just as they accept the rebuilt private compiler CLI. No private compiler
or seed DLL is included in the pacman package.
