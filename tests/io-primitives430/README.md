# Original System.IO and System.Reflection.Primitives 4.3.0 packages

Both original packages are built from pinned source-build-reference-packages
commit `5aeee2738338530a92d7f6caa2c7d5f569fed3c4`, archive SHA-256
`2b3136fab488246d0289e622797094e7c2eb29b35f67a9a5cd1312ef3ddfca79`.
All four reference-source files are unchanged. System.IO has Standard 1.0, 1.3
and 1.5 profiles with 321, 314 and 339 API entries. Reflection.Primitives has a
Standard 1.0 profile with 462 entries. Each package retains its original
netcore50 byte alias, all framework markers and exact dependency groups.

Source Csc 4.4 compiles the references with warnings as errors against the exact
original source contract scopes. A source Cecil port restores the old IO
Standard 1.0 signing attributes and removes its extra automatic Debuggable
attribute. Version resources are compiled from frozen original data with LLVM
RC, preserving the original strings and language. All original API entries,
identities, public keys, attributes, dependencies, native version fields,
resource inventories and reference-only markers are checked. Full forwarded
type names, flags, scopes and nesting are compared for every profile, including
the two IO exception forwards to System.Runtime in Standard 1.3/1.5.

System.IO also retains the original NET462 runtime/reference facade alias.
Its 16 forwards come from the public definitions and exported types of the
source Standard 1.5 contract. Fifteen targets exist in the installed source
Framework mscorlib reference. InvalidDataException targets Framework System.dll,
with identity 4.0.0.0/b77a5c561934e089. A private reference-only System seed
contains this one complete public exception contract; it is never installed
as a System runtime or distributed as a NuGet dependency.

The private exception declaration is generated by the source GenAPI bootstrap
from SDK commit `e9d13cbe7e8c1d52ce276a8655f52a87e1017c46`, using source Roslyn
4.8.0. The original SDK declared Workspaces 4.8.0-3.23524.11; the bootstrap
difference is explicit. Hash-pinned Framework reference metadata supplies the
declaration data. No publisher body is copied and no published DLL enters a
compiler reference list or executes. The frozen raw GenAPI output is retained;
the compilation projection selects the one namespace and restores its original
Serializable flag. All four public entries, including the original
SystemException base, match the metadata baseline. It is a selected compiler
contract, not the complete Framework System reference assembly.

Pinned CoreFX commit `4d1af962ca0fede10beb01d197367c2f90e92c97` declares both
NET462 targeting seeds, partial-facade generation, package profile and 4.1.1.0
assembly version. Original published version/attribute metadata is data for
the generated facade header. All 16 emitted forward names, flags and scopes
match. Five forwards, including InvalidDataException across the System scope,
resolve through the exact source facade on source NET8; a forwarded MemoryStream
constructor and binary write/read execute. Original NET462 runtime execution,
the complete targeting pack and historical build tools remain open.

The archives preserve eight original DLL paths, 44 empty framework markers,
60 localized XML files and 29 dependency groups. XML and original Microsoft
license/notice text are pinned published **data**, copied byte for byte rather
than claimed as newly generated documentation. Original nuspec minimum versions
and framework selections are verified with the source NuGet libraries. Fresh
Standard 1.0/1.3/1.5, NET8 and NET462 restore probes check exact cached archive
bytes and original compile/runtime assets; genuine missing packages are recorded.
