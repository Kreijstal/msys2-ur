# EventLog 9.0.11, original NET9 profiles

Builds unchanged runtime commit `fa7cdded37981a97cec9a3e233c4a6af58a91c57`
Windows NET9 implementation and generic unsupported-platform assembly. The
package retains Microsoft public signing, assembly version 9.0.0.0, Windows
annotation, all neutral resources, original IntelliSense XML and
DisableRuntimeMarshalling. NuGet selects the Windows implementation and message
DLL for Windows RIDs, with the generic unsupported assembly as compile asset.

Both interop generator projects rebuild from the same runtime archive as private
NET8 tools with source Workspaces4.9.2. The generic assembly is generated by the
original GenFacades targets from runtime9-pinned Arcade
`6666973b629b24e259162dba03486c23af464bab`, privately built for NET8 using source
Roslyn4.14 and MSBuild17.8.49. Original GenFacades targets are NET9/NET472 with
Roslyn4.8 and MSBuild.Tasks17.8.29; those exact tool profiles remain unfinished.

The original NETStandard2.0 message DLL is compiled against source references.
`windmc -n` regenerates all 65536 message entries from the original `.mc` source;
LLVM windres compiles the original numeric-type RC file. No checked-in binary
resource is consumed as a compiler input. The regenerated resource is compared
with the archived data, and all message IDs are checked through native Windows
FormatMessage with Unicode insertions. The message assembly uses the original
servicing assembly-version rule (9.0.0.11, outside the runtime/desktop pack list).

`makepkg --cleanbuild --force --noconfirm` performs a standalone source build.
Checks restore from the candidate feed with a fresh cache, verify exact NuGet
asset selection and bytes, compare both assemblies with all original NET9 API
reference inputs, and execute real read-only classic/modern event log operations,
metadata, XPath, bookmarks, an existing-event callback and GC/disposal cases.
An independent native EvtQuery verifies the selected event record. Generic
unsupported metadata and representative throwing APIs are checked separately.
No event writes or channel configuration saves are required.

Original NET8, NETStandard and .NET Framework EventLog profiles, original compiler
preview/toolset reproduction, full MSBuild/SDK10, desktop10 and PowerShell7.6
remain unfinished. Runtime execution checks use source NET10; no NET9 runtime
is supplied by this package.
